# VERDANA — Premium Intelligent Plant Care Platform

VERDANA is a high-end, immersive, and scientific smart plant care platform designed to bring premium aesthetics and real-time biological diagnostics to your indoor botanical companion spaces. Built with a modern, high-performance tech stack, VERDANA bridges the gap between expert horticulturist knowledge and elegant digital living.

## ✨ Features

### 1. 🌌 Immersive Cinematic Landing Page
* **Interactive Fluid Dynamics:** Floating glass cards (Today's Care, Happy Plants) respond gracefully to mouse cursor movements.
* **Ambient Dark Botanical Mood:** A curated dark palette (`#07110d`) with a subtle film-grain overlay and custom organic glowing drop shadows.

### 2. 🧪 Real-Time Care Clinic (Care Guide)
* **Dynamic Specimen Selector:** Clean responsive sidebar showcasing high-fidelity specimens (Monstera, Snake Plant, Fiddle Leaf Fig, Aloe Vera, Golden Pothos, Calathea, Rubber Plant, etc.).
* **Active Parameters Panel:** A sticky desktop sidebar updating metrics on-the-fly:
  * **Water Optimizer:** Smooth range slider simulating real-time transpiration calculations.
  * **Environmental Profiles:** Light levels and non-toxic pet-safety certifications.
  * **Interactive Leaf Diagnostic:** Instant troubleshooting presets (e.g., wrinkly upright leaves, soft mushy stems) to isolate symptoms.

### 3. 🔍 Intelligent Neural Scan (Identification)
* **Preloaded Calibration & Custom Uploads:** Test with curated plant profiles or drag-and-drop high-res botanical files.
* **Level-Balanced Layout:** Symmetric split-screen design pairing neurological scanning indicators directly next to a balanced specimen list.

### 4. 🌿 Growers Society (Community)
* **Botanical Discussion Streams:** Filtered topics (Global Greenhouse, Indoor Jungle, Succulent Guild, Milestones, and Care Q&A).
* **Smooth Sidebar Navigation:** A fully sticky "Botanical Rooms" box following your screen continuously as you read and discuss.

### 5. 🛠️ Premium Technical Architecture
* **Vite + React + TS:** Instant hot-module replacement and clean type definitions.
* **Tailwind CSS + Framer Motion:** Fluid hardware-accelerated transitions, custom glassmorphism utilities (`.glass`, `.glass-strong`), and dynamic layout shifting.
* **Fluid Viewport Sticky Hooks:** Bypasses standard scroll constraints by managing clean, scrollable column contexts natively.

## 🚀 Getting Started

### Prerequisites
Make sure you have Node.js (v18+) installed.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Hafsa2122/Verdena-premium-plant-care.git
   cd Verdena-premium-plant-care
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
